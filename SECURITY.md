# Security Policy

## Reporting a concern

Do not open a public issue containing credentials, access keys, tokens, account IDs, ARNs, IP addresses, email addresses, private keys, or unredacted AWS console content.

For a repository concern, contact the maintainer through the GitHub profile associated with this repository and provide only the minimum non-sensitive context needed to begin a private conversation.

## Repository boundaries

This is an educational monitoring case study. It contains templates and redacted evidence, not AWS credentials or a production incident-response service. If you discover sensitive content committed to the repository, report the file path and commit reference without reproducing the sensitive value in a public discussion.
